- **Sync all is more accurate** when it times lyrics by listening (for example lyrics from Genius or pasted text):
  - The speech model often places the first word after a pause far too early, inside the silence before it. Lines now start where the singing actually starts.
  - Lines the model didn't hear are placed inside the singing between their neighbours, never in an instrumental break, and are moved onto a nearby start of singing.
  - Lines missing at the very start or end of a song are spaced using how fast the words go in the rest of that song.
  - A single short word matched by chance no longer pins a whole line to the wrong place.
  - Fit the voice band to the singer before pressing Sync all: the better the green "singing" lane matches the voice, the better this works.
- **Genius on the web version**: a website that hosts the web build can now offer Genius search as well (it needs a small relay on the server; see the notes at the top of the web file). lyrics.smegolas.com has it.
- The web version only searches Genius where that works, so there is no more "Couldn't reach Genius" message.
