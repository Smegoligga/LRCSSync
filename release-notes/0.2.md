- Embed lyrics into the song file (MP3, FLAC, Ogg, Opus, M4A, WAV and more), either into the original or a copy. Players like Poweramp then show them without a separate .lrc file. Opening a song also loads lyrics already embedded in it.
- Lyrics are split into sections (verse, chorus and so on), using [Chorus] style headers or repeated lines. Each section gets a colour on the timeline and a header in the list.
- Copy timing to repeats: time one chorus, then the app finds the other choruses in the audio and times them the same way.
- Instrumental parts are marked on the timeline. "Add breaks for instrumental parts" in the menu adds an empty line at each one, so the last lyric doesn't stay on screen.
- Playback speed from 0.1x to 4x, with [ and ] to change it.
