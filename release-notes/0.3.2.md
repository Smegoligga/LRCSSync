- **Embed lyrics on the website**: lyrics.smegolas.com can now write the lyrics into the song file, using the same code as the apps (MP3, FLAC, Ogg, Opus, M4A, WAV and more). In Chrome or Edge on a computer, "Write into this song" overwrites the song you opened; other browsers download a copy with the lyrics in it. Songs that already have lyrics embedded open with them on the website too.
- **Updates**: the apps check GitHub for a new version once a day and tell you when one is out; About shows whether you're up to date. The website always runs the newest version (lyrics.smegolas.com updates itself within about 10 minutes of a release).
- **About** has buttons for GitHub, smegolas.com and, on Android, **Add to Obtainium** for automatic updates (turn on "Include prereleases" for this app in Obtainium).
