- **Sync all**: one button that times every line. If the lyrics are already timed, it fits them to your recording and lines each line up with where the singing starts. If not, it listens to the song and matches the lyrics to the words it hears. Lines it isn't sure about are marked with an orange time and a "?".
- **Write lyrics from the audio** (Lyrics > From audio): listens to the song and writes timed lyrics. While it listens it looks the song up, and when it's sure which song it is, it uses the real lyrics instead of a guess.
- Speech recognition runs on your device using a Whisper speech model, downloaded the first time you use it (Tiny, Base or Small in Settings). On Linux it can be slow.
- **Different versions**: synced lyrics from a version with a longer intro (or a slightly faster or slower one) are shifted and stretched to fit your recording automatically. Also in the menu as "Fit timing to this recording".
- **Genius**: search now covers Genius too. If Genius asks for a check, a Genius window opens and sends the lyrics back once you pass it (turn off your VPN if it keeps failing). On phones it opens in the browser so you can copy the lyrics and use Paste from clipboard.
- Headers like [Chorus], [Verse 1: Artist] or [Artist name] are used as sections, not lyrics. Lines like "Contributors" or "Embed" from copying a lyrics page are removed.
- Search results show where they're from, the release year when known, and whether the lyrics are explicit or censored. **Uncensor** puts the original words back into censored lyrics using an uncensored version of the song, keeping the timings.
