Open a .lrc file (timed) or a .txt file (plain lyrics to time yourself).

      

    

    

      
Listens to the song and writes the lyrics with their timings. While it listens it also looks the song up, and if it's sure which song it is, it uses the real lyrics instead.

      
Runs on this device. The first time, it downloads a speech model (see Settings). Check the words afterwards: it mishears some, especially over loud music or fast rap.

      

    

    
Replacing your lyrics can be undone with Ctrl+Z.

  

  
    
Embed lyrics

    
Writes the timed lyrics into the tags of , so players like Poweramp show them without a separate .lrc file. Any lyrics already in the file are replaced. The audio itself isn't changed.

    

      
      
    

    
This browser can't change files on your device, so you get a copy to download. In Chrome or Edge on a computer, open the song with the Open button (or drag it in) and "Write into this song" overwrites it directly.

Keyboard shortcuts

    

      
SpacePlay / pause

      
Enter or TTap: time the selected line and go to the next

      
SSet the selected line to the playhead

      
Up / DownSelect the previous / next line

      
Left / RightNudge 50 ms (Shift 10 ms, Ctrl 100 ms)

      
, / .Jump back / forward 2 s

      
PPlay from the selected line

      
[ / ] / \Slower / faster / normal speed

      
E or F2Edit the selected line's text

      
I / DelInsert a line below / delete the line

      
Ctrl+H or Ctrl+FFind and replace a word in every line

      
ASync all

      
BAdd breaks for instrumental parts

      
G / R / LSnap / Move following / Loop line

      
+ / - / 0Zoom in / out / fit

      
Ctrl+Z / Ctrl+Shift+ZUndo / redo

      
Ctrl+O / Ctrl+SOpen song / save .lrc

      
Hold on the timelineZoom in while held (drag to fine-tune, release to zoom back)

      
Alt while draggingDon't snap

      
Ctrl + scroll / pinchZoom
