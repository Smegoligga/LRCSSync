Embed lyrics

    
Writes the timed lyrics into the tags of , so players like Poweramp show them without a separate .lrc file. Any lyrics already in the file are replaced. The audio itself isn't changed.

Keyboard shortcuts

    

      
SpacePlay / pause

      
Enter or TTap: time the selected line and go to the next

      
SSet the selected line to the playhead

      
Up / DownSelect the previous / next line

      
Left / RightNudge 50 ms (Shift 10 ms, Ctrl 100 ms)

      
, / .Jump back / forward 2 s

      
PPlay from the selected line

      
[ / ] / \Slower / faster / normal speed

      
E or F2Edit the selected line's text

      
I / DelInsert a line below / delete the line

      
BAdd breaks for instrumental parts

      
G / R / LSnap / Move following / Loop line

      
+ / - / 0Zoom in / out / fit

      
Ctrl+Z / Ctrl+Shift+ZUndo / redo

      
Ctrl+O / Ctrl+SOpen song / save .lrc

      
Hold on the timelineZoom in while held (drag to fine-tune, release to zoom back)

      
Alt while draggingDon't snap

      
Ctrl + scroll / pinchZoom
